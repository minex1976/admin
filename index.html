Referral data format the loader expects

Referral map — /referrals/<referrerId>/<referredId> = true or { name, timestamp }. Also tried: /userReferrals, /referralData, /referralTree, /invites.

Per‑user referredBy — /users/<userId>/referredBy = referrerId or { referrerId, timestamp }. The loader inverts this. Also tried on /players, /profiles, /accounts.

Earnings — one of these shapes (any one is enough):
• /referralEarnings/<referrerId> = number
• /referralEarnings/<referrerId> = { total, currency }
• /referralCommissions/<referrerId>/<referredId> = number (per‑referral, summed automatically)
• /users/<referrerId>/referralEarnings (or referralBalance, commissionEarned, earnings) = number

Also probed: /referralBalances, /referral_earnings, /referral_balance, /referralRewards.
