Firebase data format the loader expects

Primary paths: /analytics/gameHistory/YYYY-MM-DD/room_15/<gameId> and /analytics/gameHistory/YYYY-MM-DD/room_30/<gameId>.

It must also contain a human player count via humanPlayerCount, humanCount, humans, humanPlayers, realPlayers, playerCount (with botsExcluded:true), totalPlayers, or a players object where bots are marked isBot: true.

Referral data format the loader expects

The loader tries these structures in order and stops at the first one that exists:

1. Referral map — /referrals/<referrerId>/<referredId> = true or { name, timestamp, … }
Same idea also tried at /userReferrals, /referralData, /referralTree, /invites.

2. Per‑user referredBy — /users/<userId>/referredBy = referrerId or { referrerId, timestamp }. The loader inverts this to build the referrer → referred list. Same idea also tried at /players/<id>/referredBy and /profiles/<id>/referredBy.

Names are looked up from /users/<id>/name (or /username, /displayName) and the same at /players and /profiles.

If your structure is different, click Diagnose Referrals and copy what it prints — you can then tell me the shape and I'll wire it up.
