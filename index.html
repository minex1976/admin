Firebase data format

This dashboard connects directly to Firebase Realtime Database and reads /analytics/gameHistory/YYYY-MM-DD/room_15/ and /analytics/gameHistory/YYYY-MM-DD/room_30/ only when you press Analyze / Refresh. It does not subscribe to live room/player state. Each record needs a timestamp and a reliable humanPlayerCount (or a players object with isBot: true for bots).

Example: /analytics/gameHistory/2026-10-11/room_15/12345 → { timestamp: 179..., hour: 14, humanPlayerCount: 40, botPlayerCount: 3 }.

Note: The dashboard can only analyze records that already exist in Firebase. It cannot recreate older rounds that were never saved.
