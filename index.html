Firebase data format the loader expects

Primary paths: /analytics/gameHistory/YYYY-MM-DD/room_15/<gameId> and /analytics/gameHistory/YYYY-MM-DD/room_30/<gameId>.
Fallback paths (used if the primary path is empty): /gameHistory/…, /analytics/games/….

Each round should contain at least one of: timestamp, startedAt, createdAt, endedAt, ts, time, hour — or a Unix‑timestamp record key. It must also contain a human player count via humanPlayerCount, humanCount, humans, humanPlayers, realPlayers, playerCount (with botsExcluded:true), totalPlayers, or a players object where bots are marked isBot: true. Records missing both are counted as “skipped” rather than treated as zero.
